Papertrail didn’t start

You are most likely opening this HTML file directly. That cannot work: browsers refuse to load a modern app’s scripts over file://, so nothing runs. Papertrail has to be served over http:// — even locally.

Build it and serve it:

npm install
npm run build
npm run preview

Then open the http://localhost:… address it prints. For day-to-day development use npm run dev instead.

If you are hosting this: publish the dist/ folder, not the repository root. The file at the repo root is a build template, not a working page.

The page loaded but the app did not start. That usually means the browser is too old for it, or a file failed to download on a poor connection.

Worth trying, in order: reload the page, then close and reopen the browser tab.

If it still fails, the browser is probably the problem — updating it, or opening the link in Chrome, Firefox, or Safari, should sort it.
